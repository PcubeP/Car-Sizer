# Car Sizer

Side-by-side visual car comparison tool. Pick any two cars, see them rendered as accurate silhouettes at the same scale, and instantly compare dimensions — length, width, height, wheelbase — alongside real parking bay standards.

## Features

- **To-scale silhouettes** — both cars rendered at the same pixel-per-metre ratio so proportions are immediately obvious
- **Live dimensions** — fetched from Wikidata, so the catalogue stays current without a backend
- **Parking bay overlay** — toggle standard bay sizes (UK, US, EU) to see how each car fits
- **Alignment modes** — align cars by centre, front axle, or rear axle
- **Shareable URLs** — car selection and alignment are encoded in query params

## Tech

React · TypeScript · Vite · Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
