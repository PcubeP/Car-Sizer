# Car Sizer

Side-by-side visual car comparison tool. Pick any two cars, see them rendered as accurate silhouettes at the same scale, and instantly compare dimensions — length, width, and height — alongside real parking bay standards.

## Features

- **To-scale silhouettes** — both cars rendered at the same pixel-per-metre ratio so proportions are immediately obvious
- **Dimension table** — length, width, and height from a hand-curated catalogue of published manufacturer specs, with an optional live cross-check against Wikidata for models that declare an entity ID (no backend required)
- **Parking bay overlay** — toggle standard bay sizes (India, UK, US) to see how each car fits
- **Alignment modes** — align cars by centre, front axle, or rear axle
- **Shareable URLs** — car selection and alignment are encoded in query params

## Tech

React · TypeScript · Vite · Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
